ATHAR login dashboard prototype

Open index.html in a modern browser.

- First screen presents separate Volunteer and NGO workspaces.
- Each workspace has its own login and account creation flow.
- Volunteer accounts open Discover; NGO accounts open the NGO Dashboard.
- Create one account for each role using separate email addresses.
- Accounts and data are saved in browser localStorage on this device/browser only.
- This is a prototype, not production authentication. Passwords are stored locally for demonstration.
- Real email/SMS verification and delivery require a secure backend and provider integration.
